3D Viewer — วิธีใช้งาน
1) แตก zip แล้วเปิดโฟลเดอร์นี้ผ่านเว็บเซิร์ฟเวอร์ (ห้ามดับเบิลคลิก index.html ตรงๆ เพราะเบราว์เซอร์จะบล็อกการโหลดโมเดล)
   ทดสอบบนเครื่อง: เปิด Terminal/Command Prompt ในโฟลเดอร์นี้ แล้วรัน  python -m http.server 8000
   จากนั้นเปิด http://localhost:8000
2) นำขึ้นเว็บจริง: อัปโหลดทั้งโฟลเดอร์ไปยังเว็บเซิร์ฟเวอร์/Netlify/GitHub Pages/เซิร์ฟเวอร์ภายในองค์กร
ไฟล์สำคัญ
- model.glb        โมเดล (ลดขนาดแล้ว texture 512px, meshopt)
- viewpoints.json  มุมกล้อง (ได้จาก Scene ใน SketchUp) แก้ชื่อ label ได้
- hotspots.json    รายละเอียดส่วนประกอบโครงการ 1-8 (ชื่อ, สถานะ, คำอธิบาย, รายการย่อย, พิกัด, มุมกล้อง)
                   แก้ข้อความได้โดยตรง ส่วน position/view เป็นพิกัดเมตรบนโมเดล
- ปุ่ม "รายละเอียดโครงการ: เปิด/ปิด" ซ่อนหรือแสดงหมายเลขบนโมเดลและรายการด้านซ้าย
- index.html       ตั้งชื่อโครงการ/ชื่อไฟล์โมเดลที่ CONFIG ด้านบนของสคริปต์
